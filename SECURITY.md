# Security Policy

## Supported versions

Security fixes are handled on the default branch unless maintainers document release branches later.

## Reporting a vulnerability

Please report suspected vulnerabilities privately to the repository owner instead of opening a public issue with exploit details.

When reporting, include:

- affected version or commit;
- a minimal reproduction if possible;
- impact and expected behavior;
- any suggested fix.

Do not include live secrets, credentials, tokens, or private data in reports.
